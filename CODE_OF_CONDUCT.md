# Code of Conduct / 行为准则

Treat everyone with respect. Discuss ideas constructively; harassment, discrimination, and sharing private information without consent are not acceptable. Maintainers may remove harmful content or restrict participation. Contact a maintainer through the public contact options on their GitHub profile to report concerns; do not publish private details in an issue.

尊重每一位参与者，建设性地讨论观点。不得骚扰、歧视或未经同意公开他人隐私。维护者可移除有害内容或限制参与。遇到问题时，通过维护者 GitHub 主页公开的联系方式联系，不要在 Issue 中公开隐私。
